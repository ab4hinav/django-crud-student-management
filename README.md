# Student Management System - Django CRUD

## Project Description

This project is a Student Management System developed using Django.

It demonstrates the four basic CRUD operations:

- Create
- Read
- Update
- Delete

## Features

- Add a new student
- View all students
- Edit student information
- Delete students
- Store student data using SQLite database

## Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS
- Git
- GitHub

## Student Information

The application stores:

- Student Name
- Email
- Course
- Age

## CRUD Operations

### Create
Users can add a new student using the Add Student form.

### Read
The home page displays all students stored in the database.

### Update
Users can edit the information of an existing student.

### Delete
Users can remove a student from the database.
